# ListenShorts 要件定義

最終更新：2026-11-22（M4）

短い英語動画（15〜60秒）を見て、3〜5問の聞き取りクイズを解き、次の動画へスワイプする、を繰り返す英語リスニング練習アプリ。

> 記号の意味：**【決定】** はユーザー（So）と合意した点、**【Claude 決定】** は Claude が決めて確認を待っている点、**【未確認】** はまだ確かめていない点。

---

## 1. 背景と目的

- 利用者の聞き取りは「中級の停滞期」。2026-11-11 の測定では、書き取りの正答率が「興味のある動画」で 84.5%、「興味のない雑談」で 57.3%、「映画の速い会話」で 53.7%
- 誤りの約3分の2は「知っている単語なのに聞き取れない」もの。多いのは次の4つ
  1. L と R の取り違え（Arizona→Alizona、spray→splay）
  2. 機能語・弱形の脱落（a / the / it / was / were / been）
  3. 語末子音の脱落（called→code、code→coke）
  4. 連結による単語の切れ目の誤り（signs were reportedly→sience repory）
- 書き取りは効果があるが、全文を書き取るのは続かない。**短い動画とクイズ・ゲームの形で、毎日続けられるようにする**のが目的

## 2. 前提

| 項目 | 内容 |
|---|---|
| 利用者 | 本人1人だけ【決定】 |
| 主な端末 | **iPhone**（Safari／ホーム画面に追加した PWA）。PC（Windows）のブラウザでも使える【決定】 |
| 開発とプレビュー | 手元の PC では動かさない。Vercel のプレビュー URL で確かめる【決定】 |
| 画面の言語 | 日本語（問題文と英文は英語） |
| リポジトリ | `so-studnet/listen-shorts`（**公開リポジトリ**）【決定】。本物のクリップパックはコミットしない（7章） |
| アプリ名 | ListenShorts【決定】 |

## 3. 用語

| 用語 | 意味 |
|---|---|
| クリップパック（パック） | 動画の区間・正解の文・問題をまとめた JSON。別のチャットで Claude が作る。形式は `docs/pack-format.md` |
| クリップ | 1本の動画の中の、15〜60秒の区間。3〜5問の問題を持つ |
| 文（sentence） | クリップの中の1文と、その再生区間 |
| 問題（item） | 1つの文にひもづく1問。形式は穴埋め・聞き分け・並べ替え |
| タグ | 問題が狙う誤りの種類：`function_word`／`l_r`／`final_consonant`／`linking`／`vocab`／`other` |
| 判定 | 正解（correct）／惜しい（close）／不正解（wrong） |

## 4. 機能要件

### F1 クリップの再生

- YouTube の公式埋め込みプレーヤー（IFrame Player API）で、クリップの `start`〜`end` だけを再生する
- iPhone では音声つきの自動再生ができないので、最初は「タップして再生」ボタンを出す
- インライン再生（`playsinline=1`）にして、iPhone で全画面に切り替わらないようにする
- 字幕は既定で出さない設定（`cc_load_policy=0`）にする
  - 【未確認】YouTube の自分の設定で字幕を常にオンにしていると、表示される可能性がある。M1 で実機で確かめる
- 区間の終わりは、再生位置を短い間隔で見て止める。【未確認】0.2〜0.3秒ほどずれる見込み。文の終わりが切れないよう、区間の後ろに余白（定数 `PLAYBACK_TAIL_PADDING`、初期値 0.3秒）を足す
- プレーヤーはクイズ中も小さく表示したままにする（YouTube の規約で、プレーヤーは見える状態にしておく必要があるため）
- 動画が埋め込み禁止・削除済みなどで再生できないときは「この動画は再生できません」と出し、そのクリップを飛ばせるようにする

### F2 1本のクリップの流れ

1. **視聴**：字幕なしでクリップ全体を1回再生する。終わったら（または「クイズへ」を押したら）クイズに進む
2. **クイズ**：`items` の順に3〜5問を出す
   - 各問題の画面で「この文を聞き直す」ができる（ライフ1）。「全体をもう一度見る」もできる（ライフ2）【決定】
   - 解答後（判定の画面）の聞き直しは無料【Claude 決定】
   - **解答は1問につき1回**。答えたらすぐに判定・正解・解説（`note`）を出す【決定】
3. **結果**：正答率、得点、最大コンボ、獲得 XP、新しく獲得したバッジ、レベルの上昇。間違えた問題（惜しいも含む）の、正解の文・自分の答え・解説を並べる。文ごとに聞き直せる（結果画面ではライフは消費しない）
4. **次へ**：上にスワイプするか「次のクリップ」ボタンで、フィードの次のクリップへ

### F3 問題の形式と判定

出題の割合の目安は、穴埋め7割、聞き分けと並べ替えで3割。割合はパックを作る側で調整する（アプリは `items` の順に出す）。

#### 穴埋め（cloze）

- 文の `text` のうち `answer` の部分（1〜4語）を空欄にして表示する。空欄の長さは語数がわかる程度にし、文字数はわからないようにする
- 判定（`src/lib/domain/answer.ts`）
  - 大文字小文字と句読点は無視する。曲がったアポストロフィ（’）も `'` と同じに扱う
  - 短縮形は展開してから比べる（we're = we are、can't = can not など）
  - `accept`（別解）のどれかに一致しても正解（例：`10` と `ten`）
  - **惜しい**：5文字以上の語で、綴りが1文字だけ違う（置換・挿入・削除）。得点は半分、綴りミスとして記録する
  - 【Claude 決定】**l と r の入れ替え1文字（spray→splay）は「惜しい」にせず不正解**。綴りミスではなく聞き取りの誤りなので、L/R の練習として数える
  - 語数が違えば不正解（機能語が抜けた場合など）
- 入力欄では、自動修正・自動大文字・予測変換・スペルチェックを切る（`autocorrect="off"` `autocapitalize="off"` `spellcheck="false"`）。iPhone で入力欄が勝手に拡大されないよう、文字サイズは 16px 以上にする【Claude 決定】

#### 聞き分け（choice）

- `answer` の部分を空欄にした文と、2〜4個の選択肢（例：light / right）を出す。選択肢の並びは毎回シャッフルする
- 完全一致で判定する（惜しいはない）

#### 並べ替え（order）

- 文の `answer` の部分を、語ごとのカードに分けてシャッフルする（元の順と同じにならないようにする）
- カードをタップした順に並ぶ。並んだカードをタップすると戻せる。全部並べたら「答える」
- 句読点は外してカードにする。同じ語が2枚ある場合は、語の並びが正しければ正解（カードの区別はしない）【Claude 決定】
- 順序の完全一致で判定する

#### 共通

- 解答後、パックの `note`（解説）と、正解の部分を強調した文の全体を出す
- 各問題にはタグを付ける（パックで指定）。タグは「その問題が狙う誤りの種類」。記録画面ではタグごとに正答率を出す

### F4 ゲーム要素

数値はすべて `src/lib/domain/constants.ts` に定数としてまとめ、調整しやすくする。

#### 得点

```
得点 = round(基本点 × ヒント係数 × コンボ倍率) + スピードボーナス
```

| 要素 | 値 |
|---|---|
| 基本点 | 正解 100、惜しい 50、不正解 0 |
| ヒント係数 | ヒントを使ったら 0.5、使わなければ 1 |
| コンボ倍率 | 下の表 |
| スピードボーナス | 下の表。正解（惜しいは除く）かつヒントなしのときだけ。コンボ倍率はかけない |

#### コンボ【決定】

| 連続正解数（この問題を含む） | 倍率 |
|---|---|
| 1 | ×1.0 |
| 2 | ×1.2 |
| 3 | ×1.5 |
| 4 以上 | ×2.0（上限） |

- 不正解でコンボは 0 に戻る
- **惜しい**：コンボは切れないが、増えもしない。そのときの倍率をかける【決定】
- クリップをまたいでも続く。アプリを閉じても続く（保存する）
- 復習ではコンボを使わない（変化もしない）

#### スピードボーナス【決定】

| 形式 | 制限時間 | ボーナス |
|---|---|---|
| 穴埋め | 15秒 | +20 |
| 並べ替え | 15秒 | +20 |
| 聞き分け | 8秒 | +20 |

- 時間は問題を表示したときから数える。**聞き直しの再生中は数えない**【決定】

#### ライフ

- クリップごとに 3。文の聞き直しで1、全体の見直しで2を使う。足りないときはボタンを押せない
- クリップの終わりに、残ったライフ1つを 30点に換算する（XP にも入る）

#### ヒント

- 穴埋めのみ。空欄の**各語の最初の1文字**を見せる（例：`a_ a_______ b______`）【Claude 決定】
- 使うとその問題の得点が半分。スピードボーナスはなくなる

#### XP とレベル

- 得点 = XP。復習の XP は別に決める（F5）
- レベル n から n+1 に上がるのに必要な XP：`500 + 250 × (n − 1)`【Claude 決定】
  - 1本で 400〜700 XP ほど取れる見込みなので、最初は1〜2本で上がり、Lv10 には約 13,500 XP（25本前後）、Lv20 には約 52,000 XP（90本前後）
- 称号（レベルの下限で決まる）【Claude 決定。文言は変えてよい】

| レベル | 称号 |
|---|---|
| 1 | 見習いリスナー |
| 3 | 耳ならし中 |
| 5 | 弱形に気づく人 |
| 8 | 聞き分け職人 |
| 12 | 連結ほどき |
| 16 | 速い会話の追跡者 |
| 20 | 字幕いらず |
| 30 | ネイティブの耳 |

#### バッジ

条件はデータ（`src/lib/domain/badges.ts` の配列）として定義し、後から足せるようにする。条件は解答記録とクリップの結果から計算する。一度取ったバッジは消えない。

| ID | 名前 | 条件 |
|---|---|---|
| `first_clear` | 初クリア | クリップを1本最後まで解く |
| `lr_master` | L/R マスター | `l_r` タグの問題に10問連続で正解（他のタグの問題は間にはさまってもよい。惜しいは連続を切る） |
| `function_hunter` | 機能語ハンター | `function_word` タグの問題に累計50問正解 |
| `no_miss` | ノーミスクリア | 1本の中で全問正解（惜しいは不可、ヒントは可） |
| `life_saver` | ライフ温存 | 1本の中でライフを使わずに全問正解 |
| `uk_10` | イギリス英語 10本 | `accent` が `UK` のクリップを10本最後まで解く（同じクリップの再挑戦は数えない） |
| `perfect_combo` | パーフェクトコンボ | 1本の中で全問、ヒントなし・スピードボーナスつきで正解【Claude 決定。`no_miss` と差をつけるため】 |

- バッジはクリップを解き終えたときに判定する。M2 までの解答記録には「どの回の解答か」（`sessionId`）とスピードボーナスが残っていないので、`perfect_combo` の判定には M3 以降の記録だけを使う

#### 再挑戦【決定】

- 一度最後まで解いたクリップは、フィードの後ろに回る。再挑戦できる
- 再挑戦の XP（得点）は半分。解答は記録し、統計と復習にも反映する

### F5 復習

- 間違えた問題（不正解と惜しい）を復習キューに入れる。すでに入っていれば、最初の段に戻す
- 間隔は段階式：**1日 → 3日 → 7日 → 14日 → 30日**。復習で正解すると次の段へ、不正解・惜しいで最初の段（1日後）に戻る。30日の段で正解したら「卒業」としてキューから外す
- 日付の区切りは端末の時刻の**午前4時**【Claude 決定】。夜遅くに間違えた問題が、寝て起きた直後に出てこないようにするため。「1日後」は「次の区切り（午前4時）以降」を意味する
- 復習画面では、今日が期日の問題を、期日の古い順に1問ずつ出す。問題の形式は元と同じ。プレーヤーは同じ文の区間を再生できる
- 復習では、**聞き直しは何回でもできる**（ライフなし）。ヒントは使える【Claude 決定】
- 復習の XP は、基本点の**半分**（ヒントを使えばさらに半分）。コンボ・スピードボーナス・ライフの換算はなし【Claude 決定】
- フィードで正解しても、キューにある問題の段は変えない。再挑戦で間違えた問題もキューに入れる【Claude 決定】
- 復習タブのアイコンに今日の件数を出す。件数は画面を開いた時刻で数える【Claude 決定】
- パックが削除された問題は、復習キューから外す（記録は残る）

### F6 画面

下部にタブバー（**フィード／復習／記録／設定**）。スマホ幅（375px）を基準に、片手の親指で届く位置にボタンを置く。

1. **フィード**（`/`）
   - クリップを縦に並べ、1画面に1本表示する（CSS の scroll-snap で上下にスワイプ）
   - **クイズ中（問題と判定の画面）はスワイプを止める**。視聴前と結果画面ではスワイプできる【Claude 決定。途中で次へ行って解答が消えないように】
   - YouTube のプレーヤーは表示中のクリップだけに作る（ほかは題名などだけ）
   - 解き終えたクリップは、次に開いたとき（または絞り込みを変えたとき）に後ろへ回る。解いた瞬間には並びを変えない
   - 各カード：タイトル、チャンネル、アクセント、難易度、問題数、解いたかどうか
   - 絞り込み：パック、アクセント（US/UK/AU/other）、難易度（1〜5）。絞り込みの条件は保存する
   - 並び順：まだ解いていないクリップ（新しいパックから、パック内は順番どおり）→ 解いたクリップ
   - 上部に、レベル・称号・次のレベルまでの XP バーを小さく出す（コンボはクイズ中の帯に出す）
   - 結果画面に、レベルアップと新しく獲得したバッジを出す
2. **クイズ**（フィードのカードの中で進む。URL は変えない）
3. **結果**（同上）
4. **復習**（`/review`）：今日の件数を出し、「始める」で1問ずつ解く。終わったらまとめを出す
5. **記録**（`/stats`）
   - レベル・称号・XP、獲得バッジの一覧（まだのものは条件を出す）
   - 正答率の週ごとの推移（月曜始まり）
   - **タグごとの正答率の推移**（週ごと。L/R、機能語など）
   - アクセント別の正答率
   - 正答率は「正解 ÷ 解答数」。惜しいは別の色で見せ、正答率には入れない
6. **設定**（`/settings`）
   - パック管理（F7）。M1・M2 の `/packs` はここに移した
   - 定数の確認（表示のみ）、データの書き出し（JSON）と削除

### F7 パック管理

- JSON を貼り付ける、またはファイル（`.json`）を選ぶ
- 読み込む前に検証し、エラーがあれば**行番号つき**で一覧にする（例：`12行目 clips[0].items[1].answer：文の中に "absolutly bizarre" が見つかりません`）
  - JSON の書き方の誤り（カンマ抜けなど）も行番号を出す
- 検証の内容は `docs/pack-format.md` の「検証ルール」
- 同じ `packId` がすでにあるとき：`version` が大きければ置き換える。同じか小さければ確認してから置き換える
- パックの一覧（タイトル、クリップ数、問題数、読み込んだ日時）と削除（2回押しで確定）
- 開発用に、架空の英文で作ったサンプルパックを最初から入れておく（`src/data/sample-pack.json`）

### F8 記録として残すデータ

解答1回ごとに次を保存する。記録画面の集計は、すべてこのデータから計算する。

| 項目 | 内容 |
|---|---|
| `id` | アプリで作る ID |
| `answeredAt` | 日時（UTC の ISO 文字列で保存し、表示は端末の時刻） |
| `source` | `feed`（初回）／`retry`（再挑戦）／`review`（復習） |
| `packId` `clipId` `itemId` | 問題の場所 |
| `type` | `cloze`／`choice`／`order` |
| `tags` | 問題のタグ（パックを後で直しても記録は変わらないよう、写しを持つ） |
| `accent` `difficulty` | クリップの属性の写し |
| `input` | 入力した答え（並べ替えは並べた語をスペースでつないだもの） |
| `verdict` | `correct`／`close`／`wrong` |
| `replays` | その問題での聞き直しの回数 |
| `elapsedMs` | 表示から解答までの時間（聞き直しの再生中を除く） |
| `hintUsed` | ヒントを使ったか |
| `points` | 得た得点（XP） |

ほかに、クリップの結果（`clipId`、日時、得点、残ったライフ、最大コンボ）、XP の合計、いまのコンボ、獲得バッジ、復習キュー、読み込んだパック、フィードの絞り込みを保存する。

## 5. 非機能要件

- **スマホ優先**：375px 幅で横スクロールが出ない。主なボタンは高さ 48px 以上
- **保存**：M1〜M7 はブラウザ内（localStorage）。キーに版を付ける（`listen-shorts:v1:...`）。読み込み時に壊れた要素は要素単位で捨てる。M8 から Supabase に同期
- **時刻**：日時は UTC で保存し、表示と日付の区切りは端末のタイムゾーンで計算する
- **非公開**：
  - 本物のパックはリポジトリに入れない（`.gitignore` で `packs/` と `*.pack.json` を除外）
  - M8 までは、本番 URL にはサンプルパックしか載らない。本物のパックは端末のブラウザの中だけにある
  - M8 以降は、ログインしないと使えない。パックや記録は RLS で本人しか読めない。アカウントを作ったら新規登録を止める
  - 検索エンジンに載せない（`robots: noindex`）
- **オフライン**：M7 の PWA で画面は開けるようにするが、動画の再生にはネットが必要
- **テスト**：判定・得点・コンボ・レベル・バッジ・復習の間隔・パックの検証・集計は純粋関数にして Vitest でテストする。画面は Playwright で操作して確かめる

## 6. 対象外（将来の拡張）

- 字幕から空欄や選択肢を自動で作る機能
- アプリ内での動画検索・字幕の自動取得
- 連続記録（ストリーク）、ランキング、複数ユーザー
- 発音の録音・採点

## 7. 動画と正解の文の扱い（制約）

- YouTube の字幕は、公式 API では動画の所有者しか取得できない。音声のダウンロードは YouTube の規約に反する
- そのため、動画は公式の埋め込みプレーヤーで再生するだけにし、正解の文はクリップパックで受け取る
- パックには他人の動画の文字起こしが入るので、アプリは公開しない（5章「非公開」）
